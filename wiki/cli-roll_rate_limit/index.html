Betaflight 4.5.1 settings reference

Roll rate limit

CLI setting roll_rate_limit. Works here. Parameter group CONTROL_RATE_PROFILES. Firmware type UINT16. Range 200 to 1998.

What it does

A cap, in deg/s, on the roll setpoint (the target rotation rate), applied after the rates curve. The default of 1998 is effectively off for any sensible maximum rate.

How it works

Stored in rate_limit[FD_ROLL]. The highest allowed value is CONTROL_RATE_CONFIG_RATE_LIMIT_MAX, 1998.

In this simulator

Works here. None of the simulator's menus change it, so it stays at Betaflight's default of 1998.

If you raise it

Raising it toward 1998 removes the extra cap.

A cap above the highest rate the curve can reach has no effect.

If you lower it

A lower limit caps roll below the rate srate asks for. It can be a deliberate safety setting, or a surprise if you forget it is there.

On ACTUAL, a roll limit below srate × 10 would make check 9 fail, because full stick could no longer reach the set maximum rate.
