Betaflight 4.5.1 settings reference

Simplified PIDs mode

CLI setting simplified_pids_mode. Works here. Parameter group PID_PROFILE. Firmware type UINT8. Values: OFF, RP, RPY.

What it does

Chooses which axes the simplified tuning sliders control: OFF (none), RP (roll and pitch) or RPY (roll, pitch and yaw). When it is not OFF, applying the sliders replaces the PID gains you typed for those axes.

How it works

This is simplified_pids_mode in the PID profile. applySimplifiedTuning, the Betaflight function that calculates the PID gains from the sliders, is compiled into the simulator.

In this simulator

Works here. The Betaflight default tune sets it to RPY. The expert table on the PIDs screen sets it to OFF, as Betaflight Configurator's expert mode does, so the gains you type there are the ones that fly.

If you raise it

Moving towards RPY puts yaw under the sliders as well as roll and pitch.

More axes take their gains from the sliders when the sliders are applied.

If you lower it

With OFF, gains you type, such as p_roll, stay as you typed them until a Betaflight settings file (diff) turns the mode on and applies the sliders.

With OFF, applying the sliders leaves every PID gain unchanged.
