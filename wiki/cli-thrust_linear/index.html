Betaflight 4.5.1 settings reference

Thrust linearisation

CLI setting thrust_linear. Works here. Parameter group PID_PROFILE. Firmware type UINT8. Range 0 to 150.

What it does

Compensates for thrust not rising in a straight line with motor output. Thrust is proportional to the square of the motor speed, and the motor speed does not rise in a straight line with the power level either. The compensation makes the throttle stick feel more even across its travel.

How it works

In Betaflight's code this is thrustLinearization in the PID profile, applied in the mixer (mixer.c). It raises low motor outputs more than high ones. 0 turns it off.

In this simulator

Works here. The physics model calculates each propeller's thrust as a constant multiplied by the square of its speed (kt ω²), so the non-linear behaviour this setting corrects for is present in the simulator.

If you raise it

There is more compensation. The throttle positions where the quad hovers and where it punches both shift, so the spacing between them on the stick changes.

A higher percentage applies more of the linearisation correction.

If you lower it

At 0 there is no compensation, and hover sits low on the stick because the quad has far more thrust than it needs to hover. At the normal Weight setting, the five inch makes about 5 times its weight in thrust and hovers at about 35 percent of the throttle stick.

0 is the firmware default in many profiles. Racers often use throttle_limit_type SCALE instead.
