Betaflight 4.5.1 settings reference

Min check

CLI setting min_check. Works here. Parameter group RX_CONFIG. Firmware type UINT16. Range 0 to 2000.

What it does

The PWM value below which Betaflight treats a stick as at its minimum, which matters for arming and for zero throttle.

How it works

Stored as mincheck.

In this simulator

Works here, but the quad is always armed and the sticks are analogue values from −1 to 1. It is here mainly so that a Betaflight settings file (diff) keeps its value, rather than as a minimum-throttle switch.

If you raise it

A larger part of the stick travel counts as minimum.

A higher mincheck raises the point below which a stick counts as at its minimum.

If you lower it

A smaller part of the stick travel counts as minimum.

A lower mincheck lowers that point. Never set min_check above max_check.
