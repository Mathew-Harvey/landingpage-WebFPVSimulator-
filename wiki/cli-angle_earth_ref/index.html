Betaflight 4.5.1 settings reference

Angle earth reference

CLI setting angle_earth_ref. Works here. Parameter group PID_PROFILE. Firmware type UINT8. Range 0 to 100.

What it does

Sets how much angle mode works relative to the earth frame, directions fixed to the ground, rather than relative to the quad's own axes. It changes how the quad turns when you yaw while it is banked: about a vertical line fixed to the ground, or about its own tilted axis.

How it works

This is angle_earth_ref, a value from 0 to 100, read by pidLevel when ANGLE_MODE is on. It sets the mix between the earth frame and the body frame, the axes fixed to the quad.

In this simulator

Works here. It is read only in angle mode.

If you raise it

Angle mode works more relative to the ground, and the heading behaves differently when you yaw in a bank.

A higher value gives the earth frame a larger share of the mix.

If you lower it

Angle mode works more relative to the quad's own axes.

A lower value gives the body frame a larger share of the mix.
