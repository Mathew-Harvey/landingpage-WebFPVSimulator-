Betaflight 4.5.1 settings reference

Angle feedforward

CLI setting angle_feedforward. Works here. Parameter group PID_PROFILE. Firmware type UINT8. Range 0 to 200.

What it does

Adds feedforward to angle mode. Feedforward responds to how fast the stick is moving, so the quad starts to rotate as soon as you tilt the stick, before a difference between the target angle and the measured angle has built up.

How it works

The value is stored as pid[PID_LEVEL].F, the feedforward gain of the self-levelling loop. pidLevel reads it when ANGLE_MODE is on.

In this simulator

Works here. It is read only in angle mode.

If you raise it

The quad starts to tilt sooner after the stick moves, so angle mode feels more directly connected to the stick.

A higher angle F adds a larger target rotation rate for the same speed of stick movement.

If you lower it

The quad waits for an angle error to build up before it tilts, so it responds later.

A lower angle F leaves more of the work to angle P, which acts only once there is an angle error.
