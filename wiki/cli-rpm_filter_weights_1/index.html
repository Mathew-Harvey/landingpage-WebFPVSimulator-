Betaflight 4.5.1 settings reference

RPM filter weight, harmonic 1

CLI setting rpm_filter_weights_1. Works here. Parameter group RPM_FILTER_CONFIG. Firmware type UINT8.

What it does

How strongly the first RPM notch removes its frequency. 0 leaves that harmonic alone.

How it works

This is rpm_filter_weights[0]. Exported settings use the list form that Configurator 4.5 accepts.

In this simulator

Works here, and compiled. getMotorFrequencyHz gives Betaflight each motor's speed with a delay like real motor telemetry, and the filter can remove multiples of the once-per-revolution imbalance lines. Blade passing is not modelled, so the third harmonic aims at a line that is not there.

If you raise it

The first harmonic notch removes more.

A higher weight reduces the signal more at the motor's rotation frequency.

If you lower it

The notch removes less, and 0 turns it off for this harmonic.

A weight of 0 is the clear way to say that you do not want this harmonic filtered.
