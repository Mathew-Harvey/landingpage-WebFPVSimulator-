Betaflight 4.5.1 settings reference

bat_capacity

Not simulated. Parameter group BATTERY_CONFIG. Firmware type UINT16. Range 0 to 20000.

What it does

A setting for the flight controller's battery meter: its scale, warnings and capacity. In this simulator the physics model calculates the battery voltage and current, and the Pack charge setting sets the starting voltage. These meter settings do not.

How it works

This is part of BATTERY_CONFIG and the ADC setting groups. The number of cells and each cell's resistance are fixed in the physics model.

In this simulator

Not simulated. This part of Betaflight is not compiled into the simulator, so the value is stored and has no effect. The settings catalog's own note is at the end of this page.

If you raise it

On a real flight controller this would change the battery warnings. Here, use Pack charge to change the battery.

The physics model owns the battery, so the meter settings are not read.

If you lower it

Lowering it has no effect here either.

The physics model owns the battery, so the meter settings are not read.
