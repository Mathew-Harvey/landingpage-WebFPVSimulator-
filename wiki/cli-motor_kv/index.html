Betaflight 4.5.1 settings reference

Motor kV

CLI setting motor_kv. Stored, not used. Parameter group MOTOR_CONFIG. Firmware type UINT16. Range 1 to 40000.

What it does

The kV figure on a motor's label: its speed in RPM for each volt, with nothing attached. Real setup pages ask for it, and people often type a new value here expecting the quad to fly differently. The physics model's motor constant is a value under load, not 60/(2π kV).

How it works

Stored in motorConfig.kv. Each aircraft's motor constant ke is fixed in the physics model and does not depend on this setting: on the five inch it is 0.006336 V s/rad.

In this simulator

Stored, not used. The motors belong to the aircraft chosen with the Aircraft row at the top of the Quad screen, and typing a different kV does not change them.

If you raise it

On a flight controller that used it for the on-screen display or for RPM conversion, a higher value would mean a faster motor with nothing attached. It does not change the thrust here.

The value is only stored in its setting group. The RPM filter does not convert motor speed through this setting, because the motor speed comes straight from the physics model.

If you lower it

Lowering it has no effect here either.

The value is only stored, so a lower value changes nothing.
