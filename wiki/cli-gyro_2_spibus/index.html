Betaflight 4.5.1 settings reference

gyro_2_spibus

Not simulated. Parameter group GYRO_DEVICE_CONFIG. Firmware type UINT8. Range 0 to 255.

What it does

A real Betaflight 4.5.1 setting, kept in this catalog so that a settings file loads and saves again unchanged.

How it works

It belongs to the setting group GYRO_DEVICE_CONFIG.

In this simulator

Not simulated. This part of Betaflight is not compiled into the simulator, so the value is stored and has no effect. The settings catalog's own note is at the end of this page.

If you raise it

On a flight controller that uses this setting, the quantity it names increases. Here it is kept in the settings file and changes nothing.

It is not one of the settings that pidController and mixTable read every millisecond.

If you lower it

Lowering it has no effect here either.

It is not one of the settings that pidController and mixTable read every millisecond.
