Betaflight 4.5.1 settings reference

RC smoothing auto factor (roll, pitch, yaw)

CLI setting rc_smoothing_auto_factor. Works here. Parameter group RX_CONFIG. Firmware type UINT8. Range 0 to 255.

What it does

Sets how cautious auto smoothing is on roll, pitch and yaw. A higher value usually means more smoothing, which also makes the response later. If you have a log, the active cutoff in it confirms which way it moved.

How it works

Stored as rc_smoothing_auto_factor_rpy. Auto mode uses it when it chooses the roll, pitch and yaw cutoffs.

In this simulator

Works here.

If you raise it

The sticks usually feel smoother.

In Betaflight Configurator's wording, more factor means more filtering. Betaflight's documentation for 4.5.1 gives the exact values.

If you lower it

The sticks usually feel more direct, with less smoothing.

A lower factor means less filtering.
