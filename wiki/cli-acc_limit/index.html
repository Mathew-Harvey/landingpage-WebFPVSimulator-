Betaflight 4.5.1 settings reference

Setpoint acceleration limit

CLI setting acc_limit. Works here. Parameter group PID_PROFILE. Firmware type UINT16. Range 0 to 500.

What it does

Limits how fast the setpoint, the target rotation rate set by the sticks, may change on roll and pitch. It limits how quickly the rate changes. It does not set the maximum rate.

How it works

rateAccelLimit in pid.c. Each unit is 100 degrees per second of change per second, so 10 lets the setpoint change by at most 1,000 degrees per second in one second. 0 turns the limit off.

In this simulator

Works here. The limit is applied in pid.c, to the setpoint that processRcCommand hands to the PID controller.

If you raise it

The target rate can change faster, so the quad responds to quick stick movements sooner. If you wanted a smoother response, lower it instead.

A higher limit keeps the setpoint closer to the raw stick. 0 is not the lowest limit: it switches the limit off.

If you lower it

Quick stick movements are rounded off, and a flip takes a moment to reach full rate.

At 0 there is no limit. Any other value limits how much the setpoint may change in each loop step.
