Betaflight 4.5.1 settings reference

EZ landing speed

CLI setting ez_landing_speed. Works here. Parameter group PID_PROFILE. Firmware type UINT8. Range 0 to 250.

What it does

Used when mixer_type is EZLANDING. The speed, measured by GPS, at which EZ landing stops limiting the mixer, so that a fast-moving quad keeps its full control authority.

How it works

In mixer.c the limit relaxes in proportion to the GPS speed and is gone at 2 × ez_landing_speed / 10 metres per second, so 50 means 10 m/s. At 0 the speed is not used.

In this simulator

The settings catalog marks this as working here, but it has no effect. The mixer reads it when mixer_type is EZLANDING, but the speed comes from GPS, which the simulator does not have, so the speed is always zero and this setting does not change the flight. It does not affect the simulator's own crash count either, which uses the impact speed in metres per second.

If you raise it

On a real quad with GPS, EZ landing keeps limiting the mixer up to a higher speed. In this simulator nothing changes.

A higher value means the quad must move faster before the limit is lifted.

If you lower it

On a real quad with GPS, the limit is lifted at a lower speed. In this simulator nothing changes.

A lower value lifts the limit at a lower speed.
