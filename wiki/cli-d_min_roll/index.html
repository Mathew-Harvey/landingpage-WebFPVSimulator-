Betaflight 4.5.1 settings reference

D min roll

CLI setting d_min_roll. Works here. Parameter group PID_PROFILE. Firmware type UINT8. Range 0 to 250.

What it does

The lower D value for roll. Betaflight uses it in calm flight and raises D towards d_roll when the gyro shows a fast change, such as propwash or the end of a flip, or when the stick moves quickly. The motors stay quieter in a cruise and still get full damping when they need it.

How it works

This is d_min_roll in the PID profile, and Betaflight 4.5 calls the feature D_min. It works on an axis only when d_min is above 0 and below that axis's D. The two settings that control the rise are named d_max_gain and d_max_advance in this version, although they belong to the same feature.

In this simulator

Works here. The gyro vibration and propwash in the physics model are what the rise responds to.

If you raise it

D in calm flight moves closer to d_roll, so the motors are busier, and there is less difference between calm flight and a hard stop.

A higher d_min raises the bottom of the D range. At d_roll or above, the feature is off for this axis and D stays at d_roll.

If you lower it

D is lower in calm flight, which is quieter. A fast change still raises D towards d_roll.

At 0 the feature is off for this axis, and D stays at d_roll all the time.
