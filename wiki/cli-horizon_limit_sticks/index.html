Betaflight 4.5.1 settings reference

Horizon stick limit

CLI setting horizon_limit_sticks. Stored, not used. Parameter group PID_PROFILE. Firmware type UINT8. Range 10 to 200.

What it does

Sets how far the stick must move before Horizon mode stops levelling the quad and behaves like acro. This simulator never switches HORIZON_MODE on. It has only acro and angle mode, and no mode in between.

How it works

The value is stored in the PID profile, in the level I and D fields (pid[PID_LEVEL]) and related fields, which pidLevel, Betaflight's self-levelling function, would read in Horizon mode. The simulator switches angle mode on through sim_set_angle_mode. There are no AUX channels, so no switch can turn Horizon mode on.

In this simulator

Stored, not used. A Betaflight settings file (diff) that contains these settings still contains them when you export it, but they do not change how the quad flies.

If you raise it

On a real quad with a switch set up for Horizon mode, this would change how Horizon mode flies. Here the flight does not change.

The value is only written to Betaflight's setting group. Nothing in the flight calculation reads it.

If you lower it

Lowering it has no effect here either.

The value is stored, and nothing in the flight calculation reads it.
