Betaflight 4.5.1 settings reference

Anti-gravity gain

CLI setting anti_gravity_gain. Works here. Parameter group PID_PROFILE. Firmware type UINT8. Range 0 to 250.

What it does

Sets how much anti-gravity raises the I term, and through anti_gravity_p_gain the P term, when the throttle changes quickly. It exists so that the quad does not tip in pitch or roll when you punch. Nothing measures gravity: it reacts only to fast changes in the throttle.

How it works

It works together with the ANTI_GRAVITY feature line. Betaflight measures how fast the throttle is changing, smooths that with a filter that the mixer (mixTable) updates, and multiplies the result by this gain to get the boost.

In this simulator

Works here. The ANTI_GRAVITY feature line, which switches the whole feature on or off, is a separate setting that also works here.

If you raise it

The quad stays level through a punch. With too much, its attitude jumps when you blip the throttle (raise it briefly).

A higher gain gives a larger I boost, and a larger P boost, during fast throttle changes.

If you lower it

The nose tips when you punch. This is a common fault, and you can see it in the camera view.

At 0 with the feature on, the anti-gravity code still runs but adds nothing. To switch it off completely, turn off the ANTI_GRAVITY feature.
