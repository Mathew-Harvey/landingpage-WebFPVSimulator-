Betaflight 4.5.1 settings reference

Angle limit

CLI setting angle_limit. Works here. Parameter group PID_PROFILE. Firmware type UINT8. Range 10 to 85.

What it does

Sets the largest tilt, in degrees, that angle mode will ask for. This is why the quad cannot flip in angle mode.

How it works

This is angle_limit, stored in the PID profile and read by pidLevel when ANGLE_MODE is on. Betaflight accepts values from 10 to 85 degrees.

In this simulator

Works here. It is read only in angle mode.

If you raise it

The quad can tilt further, and angle mode starts to feel more like acro.

A higher limit raises the largest tilt that angle mode will ask for.

If you lower it

The quad stays flatter. Hovering is easier, but the quad cannot tilt far enough to fly through a racing gate at speed.

A lower limit reduces the largest tilt. Less of the thrust then points sideways, so the quad cannot accelerate as hard horizontally.
