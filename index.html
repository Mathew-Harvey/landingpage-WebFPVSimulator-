07 · The reason

The hard part of FPV
is getting to the first lap.

A quad, a radio, goggles, batteries, a charger. Hundreds of dollars and a month of crashing before any of it is fun. The simulators that fix that are good, and they are still a purchase, a download, and a PC to install them on.

So I built one that asks for nothing. A tab, and the controller already on your desk.

Questions

Do I need to install anything?
No. WebFPV runs entirely in your web browser. No download, no install, no account.
What controller do I need?
You can fly with a radio transmitter or a game controller.
Can I fly Betaflight 4.5 in a browser?
Yes. WebFPV runs real Betaflight 4.5.1 flight code, compiled to WebAssembly, with the PID loop at about 1 kHz. It runs in a browser tab with no download, no install and no account.
Which browsers does it run in?
A current Chrome, Edge, Firefox or Safari with WebGL and hardware acceleration turned on.
Is it free?
Yes, and open source under GPLv3. The code is on GitHub.
